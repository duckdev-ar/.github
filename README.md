## Qué resolvemos

Trabajamos con negocios que ya funcionan y tienen algo trabado: un proceso que se hace a mano, un sistema que no habla con el otro, una herramienta que nadie entiende.

**Automatizaciones.** Lo que hoy alguien hace repitiendo pasos, puede hacerse solo.

**Desarrollo.** Sitios y aplicaciones que se adaptan al proceso real del negocio.

**Diseño.** Interfaces que se usan sin que haya que explicarlas.

## Cómo trabajamos

Primero escuchamos y entendemos cómo funciona hoy. Después proponemos. Recién ahí construimos.

Todo lo que entregamos va documentado: qué hace, cómo funciona y cómo se mantiene. Sin depender de que nos preguntes.
